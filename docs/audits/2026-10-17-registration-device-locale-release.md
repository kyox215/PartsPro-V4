## 最终语言规则

- 英语、中文、意大利语支持全站商城、注册、个人中心及后台。
- 读取设备首选语言（Accept-Language 最高优先级）：en → en-US、zh → zh-CN、it → it-IT；其它语言或缺失 → en-US。
- 用户手动选择写入当前设备的一年期 partspro_locale_device_v2 Cookie，商城与后台共用；菜单/地球按钮可恢复设备语言。此动作不再写账户资料或创建客户。
- 客户名称、商品名、地址、人工备注及其它原始业务数据保留原文。原生中文语言选项有意显示“中文/中”。
- 英文商城词典 1292 键，后台 1134 字符串叶子；固定 UI 文案/模板映射 3612 种。522 个直接英文 literal/template 调用通过显式翻译检查；三语言键和占位符契约一致。
