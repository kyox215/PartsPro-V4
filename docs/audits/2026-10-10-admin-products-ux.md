## 建议的操作顺序

日常维护：搜索或筛选 → 等待结果完成 → 打开商品 → 修改资料 → 保存 → 核对成功反馈与详情。库存只走库存动作；发布、恢复草稿、屏蔽、隐藏走状态操作。编辑已上架商品不会被文案误导为“全部重新变成草稿”。

批量隐藏：勾选本页商品 → 查看数量 → 点击批量下架 → 核对确认清单 → 确认 → 查看完整或部分执行结果 → 等待列表重读。失败项和未执行项需要核对后再选择；不自动重放整批。隐藏是软隐藏，原库存不变，可恢复到草稿并重新走上架审核。

图片维护：资料和图片分步提交；若资料已成功而图片失败，界面明确说明部分结果并保留图片。型号和供应商可选，未知兼容性不猜测。兼容性管理商品继续使用既有人工审核与权限保护。
