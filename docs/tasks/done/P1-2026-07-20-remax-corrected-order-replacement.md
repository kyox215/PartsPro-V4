# P1 · REMAX 正确订单替换错误批次

## 目标

用 `宋乾斌订单明细(1).xlsx` 重新整理 REMAX 商品、颜色规格、图片、价格与待到库存，并精确撤销错误批次 `REMAX-2026-07-A`。

## 业务影响

- 修正首页 REMAX 专区与后台待到库存来源。
- 防止客户按错误的 74 个商品和 4,507 件预购容量下单。
- 保留真实库存为 0，仅写入已下单但尚未到货的数量。

## 主责与协作

- 主责：采购到货部
- 协作：商品目录部、价格与客户部、仓库库存部、平台发布部
- 工程守门：PartsPro 业务契约、Supabase 数据与 Storage 安全门

## 范围

- 页面：主页 REMAX 专区、商品目录
- 数据：`products`、`inventory_items`、`supplier_batches`、`supplier_batch_lines`、`admin_audit_events`
- Storage：`product-images/products/imported/external/remax-2026-07/`
- 新批次：`REMAX-SONG-2026-07-A`

## 风险与自治

- 风险等级：R3 / P1（生产商品、价格、待到库存、精确删除）
- 自治等级：A2；用户已明确授权删除上一份错误导入并按正确表重做。
- 删除门：上一批必须是零客户订单、零预购占用、零实际到货、零库存锁定、零成本层和零付款。

## 已确认规则

- 汇率：1 EUR = 7.75 CNY。
- 新订单货值与运费以正确 Excel 为准；运费按货值比例分摊。
- 零售价 = 到岸成本 × 2；B2B = 到岸成本 × 1.5。
- ETA：2026-10-01 至 2026-12-01。
- 允许同型号颜色规格共用商品图。
- CB25 240W 使用包装图。

## 验收标准

- 正确订单 22 个型号、37 个颜色规格、1,144 件与 Excel 一致。
- 旧批次、74 个旧商品、4,507 件旧待到库存和 59 张旧图全部撤销。
- 新批次真实库存、可用库存和锁定库存保持 0；待到库存与预购容量均为 1,144。
- 所有 active 商品有图片、成本、零售价、B2B 价和型号；存在来源冲突或缺图的商品保持 draft。
- 首页 REMAX 专区只展示新批次可发布商品。
- 写库和 Storage 清理后完成数量、金额、依赖、订单、图片和页面 smoke 验证。

## 禁止事项

- 不删除或修改任何非 `REMAX-2026-07-A` 的商品、订单、库存或图片。
- 不把待到库存计入真实库存。
- 不在 CA09 插头规格、AS-181/182-45、RM/RB-MB02 等来源冲突未解决时强行发布。
- 不删除历史审计；以补偿审计记录本次撤销与替换。

## 验证命令

- 正确 Excel：artifact-tool inspect + 全工作表 render。
- 数据库：批次/商品/库存/预购分配/订单/成本层/付款/Storage 前后 SQL 核对。
- 工作簿：公式错误扫描 + 全工作表 render。
