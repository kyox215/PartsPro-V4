## 证据边界

以上为实际组件与原 CSS 的 Chrome 浏览器验收，API 全部使用本地合成数据。Next 图片/导航和服务端语言动作使用测试替身。无真实客户资料，无生产资金/库存/订单/权限写入；物理 iPhone、Safari 软键盘和生产登录管理员交易操作未验收。AI 共用方向稿来自此前预览阶段，不计为这些实际页面截图；图像工具没有提供可核验的 Image2 模型回执。

`qa-sources.zip` 保存本次源代码测试夹具（无环境文件、秘密、生成 bundle）。执行需本项目依赖、Chrome 及外部已安装的 Playwright；该运行库不是仓库新增依赖。完整原始截图与测试日志另保留在隔离工作树 `outputs/admin-ui-preserve-style/`。

发布记录将在当前任务与 `docs/roadmap.md` 中更新；预览资产、演示 API 和夹具均由 `.vercelignore` 排除生产上传。
